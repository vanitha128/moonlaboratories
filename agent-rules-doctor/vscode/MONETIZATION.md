# VS Code monetization decision — draft

The official [VS Code publishing guide](https://code.visualstudio.com/api/working-with-extensions/publishing-extension.md#extension-pricing-label) describes `pricing: "Free"` or `pricing: "Trial"` labels. These are Marketplace labels, **not an integrated payment or entitlement service**. Publishing still requires an authorized Marketplace publisher ID and authentication; no publisher ID was invented. A private GitHub source repository can coexist with a publicly published VSIX. A VSIX can also be distributed privately for tests.

**Recommended sequence:** publish a Free-only VS Code extension after installed-behaviour, legal, screenshots, and publisher approval. Separately decide whether to build Pro entitlements. If approved, use an authorized Moon Laboratories Stripe account with a product-specific price and a separate license service that verifies subscription state. Store an opaque token in VS Code SecretStorage. Never include workspace content, paths, findings, or diagnostics in license requests. Test activation, refresh, expiry, cancellation/downgrade, and recovery against live and sandbox states before advertising Pro. Do not reuse JetBrains Product Codes.

The existing [MoonVigil Stripe integration](https://github.com/vanitha128/pawmitted/tree/main/moonvigil) is **not** an AgentRules Doctor payment system. Its `PAYMENTS.md` says paid checkout is inactive until its own Stripe account/price/link/webhook/SMTP/database/DNS are configured and tested. Its server's `license.js` derives a MoonVigil-specific license key from a subscription ID and `webhook.js` matches a configured price, verifies paid invoice state, and records webhook events. Reusing that price, key, or entitlement would cross products and is not appropriate. Review its subscription reconciliation patterns only. No Stripe account, price, payment link, service, or contract was created as part of this draft.

**Commercial approval needed:** confirm Free-first launch vs waiting for Pro; choose monthly/yearly/one-time model, price and currency, seat/device policy, grace and refund rules, merchant account ownership, customer support terms, and privacy/legal review. A separate engineering milestone must produce genuine activation and downgrade tests. Only then choose a Marketplace `Trial` label if a real trial exists. Current release should say Free.

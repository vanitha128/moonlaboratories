Install AgentRules Doctor

  1. Open IntelliJ IDEA.
  2. Open Settings or Preferences.
  3. Select Plugins > Marketplace.
  4. Search for AgentRules Doctor. Select Install.
  5. Restart the IDE if it asks you to restart.

Check the Marketplace listing for supported IDE versions. These steps apply after the public release.

Scan a project

  1. Open a local project at its root folder.
  2. Select View > Tool Windows > Agent Rules.
  3. Wait for the scan to finish.
  4. Read the score and finding count in Health.
  5. Select a finding. Select View finding to read its details.
  6. Select Open source. Check the evidence before you change the file.
  7. Save your changes. Select Rescan.

The scan reads local files. It does not change files or run project commands.

Use the views

  • Health: Read the project score, coverage, and top findings.
  • Files: Select a file. Read its score and findings. Select Open file to inspect it.
  • Findings: Read the evidence and suggested action. Use the file and severity menus to filter the list.
  • Duplicates & conflicts: Compare repeated or conflicting instructions. Results require Pro access.
  • Settings: Check license status. Create or open the local ignore file.

Ignore a known false positive

In Settings, select Create ignore file. The plugin creates .agentrules-doctor-ignore in the project root. Use one setting on each line.

# Ignore a rule in this project.
rule DUPLICATE_DIRECTIVE

# Skip one instruction file.
file generated/AGENTS.md

Use a valid rule ID or the relative path of an existing instruction file. Save the file. Select Rescan. The plugin reports invalid settings.

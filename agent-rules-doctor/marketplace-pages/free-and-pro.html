Free and Pro checks

Free checks do not require a purchase. Pro checks require an active JetBrains license.

FreePro adds
Missing pathsJava, Node, and Python version mismatches
Missing npm scriptsExplicit npm, Maven, and Gradle dependency claims
Missing build wrappersExplicit Gradle task registration claims
Unknown simple Maven phasesRepeated directives and narrow near duplicates
Invalid ignore settingsRepeated context and narrow instruction conflicts

Both plans include Health, Files, Findings, source navigation, filters, manual rescan, and local ignore settings. The Duplicates & conflicts view has results only with Pro access.

Activate Pro

  1. Buy a license or start an available trial through JetBrains Marketplace.
  2. Open Help > Register in the IDE.
  3. Sign in with the JetBrains Account for the purchase.
  4. Select the plugin license. Select Activate.
  5. Open Agent Rules. Select Refresh license.

The status line shows Pro active when the IDE confirms access. If it shows Free checks, only Free findings affect the list and score.

Use the Marketplace Pricing page to check available plans and current prices after the public release. JetBrains manages payments, renewal, cancellation, and license delivery. Uninstalling the plugin does not cancel a subscription.

Check each finding

The plugin uses local project data and conservative checks. It cannot understand every instruction. It does not rewrite instructions or prove that a project is correct. Review the evidence before you make a change.

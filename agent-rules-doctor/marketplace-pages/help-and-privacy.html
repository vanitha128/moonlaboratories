Get help

Read the user guide first.

For a plugin problem, use the Moon Laboratories support page. Include:

  • The IDE name and version.
  • The plugin version.
  • Your operating system.
  • The steps that show the problem.
  • The expected result and actual result.

Remove secrets and private project details from logs and screenshots before you send them.

For purchases, invoices, renewals, cancellation, refunds, or license delivery, use your JetBrains Account or JetBrains Marketplace support.

Your project stays local

The scan does not upload instruction text, project files, or findings to Moon Laboratories. It does not run project commands. It does not create a Moon Laboratories account.

The scan does not change project files. The Create ignore file action creates one file only when you select it.

If you open the user guide or send a support request, your browser contacts the selected website. JetBrains manages downloads, updates, licensing, and billing under its own terms.
